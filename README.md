# Zircadia-5stage-sleep-classifier
Machine learning algorithm to classify 5-stage sleep from data collected with Zircadia’s in-ear EXG technology and gold-standard polysomnography (PSG) and output this classification to a user-friendly interface or a CSV file.


Note: 
+ Make sure to place the edf file in the database folder
+ Install all of the necessary libraries (A comprehensive list will be added later)
